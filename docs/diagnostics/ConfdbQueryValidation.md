# Ошибки запросов, найденные confdb (ConfdbQueryValidation)

## Описание диагностики

Диагностика подсвечивает тексты запросов во встроенном языке, в которых confdb
(экстрактор конфигурации 1С, проект 1c-conf-db-extractor) нашёл синтаксические
ошибки или обращения к несуществующим метаданным.

Проверка выполняется на стороне confdb по полному синтаксису языка запросов 1С
и метаданным конфигурации (объекты, реквизиты, табличные части, значения
перечислений) и сохраняется в таблицу `query_violation` базы SQLite командой
`confdb check-queries`. Диагностика активна, если в `.bsl-language-server.json`
задан `confdbDatabase`.

## Примеры

Запрос к несуществующему справочнику:
```sdbl
Запрос.Текст = "ВЫБРАТЬ 1 ИЗ Справочник.Несуществует";
```

Обрыв текста запроса:
```sdbl
Запрос.Текст = "ВЫБРАТЬ 1 ИЗ";
```
